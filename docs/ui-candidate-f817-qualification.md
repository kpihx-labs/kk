download remained a partial file while that choice awaited input. The new Save
invitation view retains its object URL until retirement instead of revoking it
after one second; its explicit link and Edge's Save choice produced a complete

virtual-key fields. The final browser-proxy repair is minimal: correct ASCII
physical codes (`KeyV`, `Digit1`), preserve original virtual-key fields and
shortcut policy, clarify help; all 46 page-action tests and Ruff pass. Restoring
control-key compatibility reopened the native picker, but no complete native
picker pass is claimed. Navigating the owned B tab through blank closed the
stale picker and preserved its private application session and identity.

No invitation/session token or long-term key was printed. Both public pairing
identities were checked. Clipboard content was not blindly read or overwritten
for cleanup; the copied invitation was consumed by its successful ceremony.

This image predates later source-only denial hints, resume wording and CLI job
controls. Those changes require their own targeted checks/replay; do not silently
assign this GUI evidence to newer on-disk bytes.
